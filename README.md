### How to Find and Join Servers

1. Launch FiveM
2. Click **"Play"**
3. Browse server list (10,000+ servers)
4. Use filters to find RP, racing, or deathmatch servers
5. Click on any server
6. Click **"Join"**
7. Wait for resources to download
8. You're in!

### How to Play Roleplay (ESX/QBCore)

1. Search for "RP" or "Roleplay" in server browser
2. Look for servers with "ESX" or "QBCore" tag
3. Join the server
4. Most require registration on Discord/website
5. Choose your character (police, EMS, civilian)
6. Follow server rules
7. Use commands like `/me`, `/do` for actions

### How to Install Custom Vehicles

1. Launch FiveM
2. Go to **"Mods"** → **"Vehicle Store"**
3. Browse or search for vehicles
4. Click **"Install"** on any vehicle
5. Vehicle downloads automatically
6. Use in any server that supports added vehicles
7. Vehicles appear in in-game shops

### How to Install ESX Framework (Server Owners)

1. Download FiveM server data
2. Go to **"Server"** → **"Resources"**
3. Search for "ESX" in resource browser
4. Click **"Download ESX Framework"**
5. Follow setup wizard
6. Configure database (MySQL)
7. Start your server

### How to Use Developer Tools

1. Press `F8` to open console
2. Type `screen` for screenshot
3. Type `record` to start recording
4. Type `stop` to stop recording
5. Type `refresh` to reload scripts
6. Type `start [resource]` to start a resource
